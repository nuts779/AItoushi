| 項目 | 内容 |
|---|---|
| プロジェクト名 | 日本株分析ダッシュボード |
| バージョン | v2.0 |
| 作成日 | 2026-04-15 |
| ステータス | プロトタイプ |

---

## 1. 背景・目的

個人投資家が半年以内の短中期運用を前提に、日本株の銘柄選定・分析・ポートフォリオ管理を効率的に行うためのダッシュボードを提供する。

Claude（AI）が分析の頭脳、Claude Code（pipeline.py）がデータ取得の実行基盤、本ダッシュボードが結果の可視化・管理UIという役割分担で構成される。

### 免責事項

本システムは公開情報の整理を目的とするものであり、金融アドバイスを提供するものではない。投資判断はユーザー自身の責任において行う。

---

## 2. ステークホルダー

| 区分 | 説明 |
|---|---|
| 主ユーザー | 個人投資家（半年以内の短中期運用を志向） |
| システム連携 | Claude（分析）、Claude Code / pipeline.py（データ取得）、yfinance（株価）、IRBANK（財務データ） |

---

## 3. システム全体像

```
[claude.ai] ─── マクロ分析・銘柄評価・ポートフォリオ提案
     ↓ Claude Code実行指示文を生成
[Claude Code + pipeline.py]
     ├─ 1段階目：yfinance → ROE/PER/PBRスクリーニング → 上位40社
     └─ 2段階目：スコア60以上 → IRBANK深掘り → 罠検出 → deepScore再算出
     ↓ final_ranking.csv 出力
[本ダッシュボード] ─── 結果可視化・ポートフォリオ管理
```

## 5. 非機能要件

| 区分 | 要件 |
|---|---|
| パフォーマンス | 初回表示 3秒以内 |
| 対応環境 | Chrome / Edge 最新版、画面幅 1280px 以上を基準（レスポンシブ対応） |
| データ更新 | pipeline.py 実行後に手動でデータを更新する形式（リアルタイム取得なし） |
| セキュリティ | 外部APIへの直接通信なし。全データはローカルのsrc/data.tsから取得 |
| アクセシビリティ | 色だけに依存せず、テキストラベルを併用して状態を識別できるようにする |

## 6. データソース定義（3層）

| 層 | 内容 | 取得手段 | 鮮度基準 |
|---|---|---|---|
| L1 | 株価・PER・PBR・ROE・配当・出来高・52週高安・時価総額 | yfinance（pipeline.py経由） | 当日〜翌営業日 |
| L2 | 決算数値・業績進捗・自己資本比率・配当履歴・連続増配年数 | IRBANK（pipeline.py --deep経由） | 決算サイクル準拠 |
| L3 | マクロ環境（NRI・第一生命・武者リサーチ） | web_fetch（Claude側） | 直近1週間〜1ヶ月 |

### 鮮度タグ定義（L2）

| タグ | 基準 | 表示色 |
|---|---|---|
| fresh | IRBANK更新から0〜30日 | 緑 |
| normal | 31〜60日 | 青 |
| stale | 61〜90日 | 黄 |
| critical | 91日以上 | 赤 |

---

## 7. 罠検出ロジック

pipeline.py（2段階目）がIRBANK取得後に自動判定する。

| 判定 | 条件 | deepScoreへの影響 |
|---|---|---|
| dangerous | 2個以上の罠フラグ | -30点 |
| suspicious | 1個の罠フラグ | -15点 |
| normal | 罠フラグなし | +0〜+8点（自己資本・増配加点） |

### 主な罠パターン

| パターン | 検出条件 |
|---|---|
| 特益込み決算（住友ファーマ型・KeePer型） | 純利益 > 営業利益 × 1.5、または直近ROE > 過去3年平均 × 2.0 |
| コロナ回復基準期歪み（共立メンテナンス型） | 過去5年に赤字あり かつ 直近黒字 |
| yfinance指標の盲点（日テレHD型） | ROEが低く見えるが直近決算で利益急改善 |

## 8. スクリーニングプリセット一覧

| プリセット | ROE | PER | PBR | 配当 | 用途 |
|---|---|---|---|---|---|
| default | 8%以上 | 5-30 | 0.3-5 | 0%以上 | 標準（半年運用） |
| value | 6%以上 | 5-25 | 0.3-3 | 1.5%以上 | PBR1倍割れバリュー |
| growth | 15%以上 | 10-50 | 1-15 | 0%以上 | 成長株（高ROE必須） |
| high_dividend | 8%以上 | 5-20 | 0.3-3 | 4%以上 | 高配当 |
| small_cap_value | 8%以上 | 5-20 | 0.3-2 | 2%以上 | 小型バリュー激縛り |
| stable_defensive | 6%以上 | 5-25 | 0.3-4 | 1.5%以上 | ディフェンシブ・地政学耐性 |

## 9. 6項目評価軸（100点満点）

| 項目 | 配点 | 評価内容 |
|---|---|---|
| ① カタリスト | /20 | 半年以内の決算・新製品・イベントの有無 |
| ② モメンタム | /20 | 業績の勢い・進捗率・前年同期比増減 |
| ③ 需給・テクニカル | /15 | 信用倍率・出来高・株価位置（52週高値比） |
| ④ バリュエーション | /15 | PER・PBR・割安度・業界中央値比較 |
| ⑤ 下値リスク | /15 | 自己資本比率・借金・地政学耐性 |
| ⑥ 配当 | /15 | 配当利回り・連続増配・権利確定 |

---

## 10. 制約事項・前提条件

- 株価対象レンジ：1,500〜4,000円（特段指定がない場合）
- 運用期間：半年以内の短中期
- Claudeの学習データに含まれる個別株情報は使用しない（古いため）
- データ取得失敗・古いデータが返ってきた場合は即座に報告し、黙って分析に進まない
- 本ダッシュボードはサンプルデータで動作し、実データはpipeline.py実行結果を手動反映する
