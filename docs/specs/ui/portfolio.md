## 1. 画面概要

最終ポートフォリオの配分・損益を管理する画面。  
コア枠（均等25%×3銘柄）とサテライト枠（各10%×2銘柄）＋現金5%の構成を視覚化する。

## 3. コンポーネント詳細

### 3.1 サマリーカード（4枚）

| カード | 計算式 | 表示色 |
|---|---|---|
| 評価額（株式） | Σ(currentPrice × shares)（cash除く） | gray |
| 損益（含み） | 評価額 - 取得額合計 | プラス=emerald / マイナス=red |
| ポジション数 | cash以外の件数（コアX + サテライトX 内訳付き） | gray |
| 現金比率 | cashポジションのallocation値 | gray |

損益カードはプラスの場合 `border-emerald-200`、マイナスの場合 `border-red-200` にボーダーが変化。

### 3.2 配分バー

| 項目 | 仕様 |
|---|---|
| 形状 | 横長バー（h-9）、portfolioPositions順に左から結合 |
| 各セグメント幅 | `style={{ width: \`${allocation}%\` }}` |
| セグメント色 | コア=bg-emerald-500 / サテライト=bg-blue-500 / 現金=bg-gray-300 |
| ラベル | allocation ≥ 10% の場合セグメント内に「XX%」テキスト表示 |
| 凡例 | バー下部に色付き■ + 種別ラベル + 銘柄名 + 配分% |

### 3.3 ポジションカード

コア枠・サテライト枠ともに同一レイアウト（コードカラーのみ異なる）。

| 要素 | 仕様 |
|---|---|
| コード | コア=text-emerald-600 / サテライト=text-blue-600 |
| 銘柄名 | text-gray-900 / font-semibold |
| 株数×買値 | 「XX株 × ¥XX,XXX」（gray小テキスト） |
| 現在値 | ¥XX,XXX（font-mono） |
| 含み損益 | ±¥XX,XXX (±XX.X%)。プラス=emerald-600 / マイナス=red-600 |
| 配分 | XX%（font-mono） |
| メモ | `note` がある場合のみ、カード下部にグレー区切り線 + 「メモ: 〜」（xs テキスト） |

**評価・推奨は表示しない。** 表示するのは買値・現在値・含み損益・配分という計算できる事実のみで、
`note` は自分で書いたメモであることが分かる形にする。
以前あった「◎ 強推奨」バッジは計算根拠のない手書き文字列だったため BUG-008 で撤去した。

### 3.4 空状態（EmptyPortfolio）

`portfolioPositions` が空のとき、サマリーカード・配分バー・ポジション一覧の代わりに表示する。

| 要素 | 内容 |
|---|---|
| 見出し | 「保有ポジションは登録されていません」 |
| 経緯 | 以前あったサンプル銘柄と推奨バッジをなぜ撤去したか |
| 登録方法 | `src/data.ts > portfolioPositions` の記述例（コードブロック） |
| 注記 | 下の「取得財務データ一覧」は保有の有無に関係なく表示される旨 |

下部の「取得財務データ一覧」は空状態でも表示する（保有と無関係にスクリーニング結果を表すため）。

### 3.5 取得財務データ一覧の「一次資料」列

各行に `SourceLinks`（compact）を置き、有報・短信へのリンクを出す。
どちらも無い行は `—`。ヘッダーには「一次資料リンクあり N社」バッジを表示する。
「取得日」は `edinetDetails[].fetchDate`＝**スクリーニング実行日**であり、画面を開いた日ではない。

### 3.6 免責事項フッター

`bg-gray-50 / border-gray-200` のボックスにテキスト中央揃えで表示。  
「投資判断・売買はご自身の責任において行ってください」を明記。

## 4. 計算ロジック

```
// 含み損益（個別）
pnl = (currentPrice - buyPrice) × shares
pct = (currentPrice - buyPrice) / buyPrice × 100

// ポートフォリオ合計
totalCost  = Σ(buyPrice × shares)   ※ type='cash' 除く
totalValue = Σ(currentPrice × shares) ※ type='cash' 除く
totalPnL   = totalValue - totalCost
pnlPct     = totalPnL / totalCost × 100
```

## 5. データソース

- `data.ts > portfolioPositions`（**現在は空**。実際に保有している銘柄を手で書く）
- `data.ts > edinetDetails` / `screeningStocks`（取得財務データ一覧）

`portfolioPositions` は `update_data.py` の更新対象外で、スクリーニングを回しても連動しない
（`dashboard.md` L-11）。以前入っていた2026年4月時点のサンプル銘柄は、
一度も保有していない架空データだったため BUG-008 で削除した。
