## 1. 画面概要

`deepScore` 90以上の銘柄を銘柄カード形式で表示する。1度に1枚展開する設計。

### 実装状況（2026-09-04 時点）

| ブロック | 状態 |
|---|---|
| カードヘッダー（順位・銘柄名・罠バッジ・株価・52週高値比・取得元・鮮度） | ✅ 実装済 |
| クイック指標6項目（PER/PBR/ROE/配当/自己資本比率/時価総額） | ✅ 実装済 |
| deepScore ゲージ（1段階目→深掘り後の増減） | ✅ 実装済 |
| **6項目評価（100点満点）** | ⚠️ **4項目65点ぶんのみ実装**（下記 3.2） |
| 財務健全性（自己資本比率・ROE・PBR・PER） | ✅ 実装済 |
| 52週レンジ内ポジション | ✅ 実装済 |
| データ取得情報（取得元・基準日・90日超警告） | ✅ 実装済 |
| 直近決算サマリー（前年同期比・通期進捗率・特別損益・業績修正） | ❌ 未実装 |
| プラス材料 / リスク要因 / 最終評価 | ❌ 未実装（`data.ts > deepStocks` に手書きデータのみ存在） |

対象銘柄は `data.ts > screeningStocks` を `deepScore >= 90` で抽出している。
仕様上の `deepStocks` 配列は現在参照されていない。

## 3. コンポーネント詳細

### 3.1 StockCard（銘柄カード）

#### カードヘッダー

| 要素 | 仕様 |
|---|---|
| ランク番号 | #N 形式、グレー大テキスト |
| 銘柄名 | 大テキスト・太字 |
| コード | （XXXX）形式、emerald色・モノスペース |
| 罠フラグバッジ | normal/suspicious/dangerous バッジ |
| 業種・IRBANK日付・鮮度 | サブテキスト行 |
| 株価 | 大テキスト・太字（右側） |
| 52週高値比 | 「52週高値比 -X.X%」（グレーサブテキスト） |
| 評価バッジ | 強く買い推奨=emerald / 買い推奨=blue / 様子見=amber / 見送り=red |
| 展開インジケータ | ▲（展開中）/ ▼（折りたたみ） |
| クリック | ヘッダー全体クリックで展開/折りたたみ。同時に1枚のみ展開 |

#### クイック指標バー（常時表示）

| 指標 | 表示内容 |
|---|---|
| PER | Xx倍（null の場合「—」） |
| PBR | Xx倍 |
| ROE | Xx% |
| 配当利回 | Xx% |
| 自己資本比率 | Xx% |
| 時価総額 | XXX億 |

背景：bg-gray-50。グリッド6分割。

### 3.2 6項目評価パネル（ScorePanel / ScoreBar）

算出できた項目のみ点数を表示し、データが無い項目は**「未算出」＋理由**を表示する。
未算出を0点として扱わないのが要点。0点にすると「評価が低い」のか「測っていない」のかが
区別できなくなり、鮮度保証の方針に反する。

| 項目 | 配点 | 状態 | 算出根拠 / 未算出の理由 |
|---|---|---|---|
| ① カタリスト | /20 | ❌ 未算出 | 決算発表予定日を取得する手段がない |
| ② モメンタム | /20 | ✅ | EDINET年次推移の前年比（純利益10 + 経常利益6 + 売上4） |
| ③ 需給・テクニカル | /15 | ❌ 未算出 | 信用倍率・出来高を取得していない |
| ④ バリュエーション | /15 | ✅ | PER 8点 + PBR 7点。PERがnullの銘柄はPER分を加点しない |
| ⑤ 下値リスク | /15 | ✅ | 自己資本比率（70%以上=15 … 30%未満=2） |
| ⑥ 配当 | /15 | ⚠️ 部分 | 配当利回りのみ（最大12点）。連続増配ぶん3点は未取得 |

- ヘッダーに「獲得点 / 算出できた満点」と「未算出N点ぶん」を併記する
- バー色：達成率 ≥75% emerald / ≥50% blue / 未満 amber
- 未算出の項目は斜線ストライプのグレーバーで表示する
- 算出ロジックは `scripts/edinet_fetcher.py > calc_score_breakdown()`
- 値は `screening_result.json` 経由で `data.ts > screeningStocks[].scoreBreakdown` に入る

**直近決算サマリー**

| 項目 | 表示 |
|---|---|
| 売上高 前年同期比 | +/-XX.X%（プラス=emerald / マイナス=red） |
| 営業利益 前年同期比 | 同上 |
| 純利益 前年同期比 | 同上 |
| 通期進捗率 | XX%（5年平均 XX%との比較） |
| 修正 | 上方/下方修正テキスト（emerald色） |
| 特別損益 | ⚠ 表示（amber色）。null の場合は非表示 |
| 次回決算予定 | YYYY-MM-DD |

#### 展開コンテンツ（右カラム）

**プラス材料（緑ボックス）**  
`bg-emerald-50 / border-emerald-200`  
箇条書きリスト（• 緑）

**リスク要因（赤ボックス）**  
`bg-red-50 / border-red-200`  
箇条書きリスト（• 赤）

**俺の本気の評価（評価色ボックス）**  
背景色は評価バッジと同系統。評価バッジ + 評価テキスト段落。

### 3.2 YoY コンポーネント

| 条件 | スタイル |
|---|---|
| val ≥ 0 | text-emerald-600 / 「+XX.X%」 |
| val < 0 | text-red-600 / 「-XX.X%」 |

### 3.3 評価バッジ定義

| VerdictRating | ラベル | スタイル |
|---|---|---|
| strong_buy | ◎ 強く買い推奨 | bg-emerald-600 / text-white |
| buy | ○ 買い推奨 | bg-blue-600 / text-white |
| watch | △ 様子見 | bg-amber-500 / text-white |
| avoid | ✕ 見送り | bg-red-600 / text-white |

## 4. インタラクション

| 操作 | 動作 |
|---|---|
| カードヘッダークリック | カード展開（同インデックスを再クリックで折りたたみ）。同時展開は1枚のみ |
| 初期状態 | インデックス0（1枚目）がデフォルト展開 |

- 6項目評価は同配列の `scoreBreakdown`
- `data.ts > deepStocks` は未参照（旧サンプルデータ）
